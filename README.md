# Folia
> **Folia** 是什么？和 Obsidian 一样：**文件系统就是数据库，Markdown 就是数据格式。**

**Folia** 是一个基于 Tauri 2 + Vue 3 + CodeMirror 6 的 Markdown 笔记管理器。本地文件夹优先、零隐藏数据库、跨平台、极轻量的 Obsidian 替代。

**Folia 没有：**
- 没有在笔记目录生成任何**隐藏配置或数据库**
- 没有常驻内存的**全文索引**
- 没有复杂的**插件市场与 CSS 脚本体系**
- 没有**白板与任务管理**
- 没有**关系图谱**
- 没有内置的**云同步**
- 没有各种**美化主题**
- 没有 **AI 助手和 Skills**

**Folia 有：**
- 任意添加**多个笔记库**
- **自动保存和可恢复的本地版本编辑历史**（零笔记库污染）
- **双栏 / 三栏浏览编辑**以及**行级文件对比（Diff）**
- **双链断链提示 & 重命名引用同步**、**列编辑与多光标**
- 可自定义的**快捷键与鼠标手势**
- 持久会话的**分栏终端窗口**
- **YAML 配色代码**直接复制粘贴，**简/繁/英/日四语界面**
- **单文件 (<9MB)**、**运行内存(<5MB)**、轻量极速启动

如果你和我一样，只是信息收集、日常写作、记录、整理和阅读 Markdown 文档，那应该用得上这款轻量笔记软件 **Folia**。

## 核心特性

### 1. 纯净的本地多工作区管理
- **多工作区并行与别名管理**：同时挂载多个本地笔记目录（支持添加不同盘符或不同路径下的同名文件夹），全局以 `(workspaceId, canonicalPath)` 唯一标识文档；右键笔记库可**自定义显示别名**（不改磁盘文件夹名）、直接查看并一键复制实际路径。
- **分笔记库 / 分文件夹独立排序与手动自由排序**：支持「名称 A→Z / Z→A / 修改时间新→旧 / 旧→新 / 手动排序」5 种方式，支持对单个笔记库及任意子文件夹右键独立设置（逐级继承并以线性图标标识）；支持同级文件/文件夹拖拽调序与右键上下移，重命名自动迁移顺序，重启完整记忆。
- **完整文件树与精准局部监听**：支持新建笔记/文件夹、重命名、复制副本、拖拽移动、在系统文件管理器中定位，删除默认移至系统回收站防止误删；文件变更监听按路径**仅局部刷新受影响的笔记库**，并自动忽略 `build_dir`、`staging_dir`、`__pycache__`、`.venv` 等常见编译缓存目录。
- **侧边栏自动隐藏、自动跟随与笔记库高亮**：支持固定显示、一键折叠或**鼠标贴边自动隐藏/滑出**；点击或切换任意标签页时，左侧文件树会自动展开所在目录、高亮所属笔记库与当前文件并平滑滚动定位。
- **持久化内嵌命令终端分栏（PTY + xterm.js）**：点击左侧栏任意笔记库横条上的终端图标，即可在右侧分栏直接打开该目录的真实交互终端（Windows 默认自动使用 Git Bash，支持自由切换 PowerShell / CMD / Zsh / 自定义路径及调整字体、字号、行高与光标样式）；**切换/关闭同栏文档或跨分栏拖拽终端时完整保留终端进程与历史输出不重启**，且打开终端后新开笔记会自动落入非终端文档栏。
- **零侵入目录结构**：不强制图片或附件存放路径，不在笔记库内写入 `.folia` 等隐藏文件夹；安装版配置与历史保存在系统应用数据目录（Windows 为 `%APPDATA%\Folia`），**Windows 便携版**在程序同级目录保留 `portable.txt` 时自动将全部数据保存在同级 `data/` 目录实现真正绿色免安装。

### 2. CodeMirror 6 双模式编辑器与 HTML 预览
- **实时预览 & 源码双栏预览一键切换**：
  - **实时预览模式**：光标离开行/块时自动隐藏语法符号并内联渲染标题、加粗、高亮、图片、可点击待办复选框、表格、提示块、数学公式与图表；完整支持嵌套行内语法（如 `**增量编译，不要 \`make dirclean\`**`、`***粗斜体***`、`==高亮 **粗体**==` 等）；光标单击进入即展开源码编辑，鼠标拖选标题或提示块标题时保持稳定不跳动、可直接复制。
  - **源码模式（自动左右双栏同步预览）**：切换至源码模式后自动在当前标签页内左右分栏（左侧源码编辑、右侧实时同步渲染预览，中间分隔条支持拖拽调比例、双击恢复 50%，支持独立开关），并提供源码图片链接**悬浮预览卡片**。
  - **阅读排版定制**：支持编辑区「靠左显示 / 页面居中」排版及居中最大行宽自定义。
- **HTML 文件浏览与源码编辑**：支持直接打开 `.html` / `.htm` 文件，在内置网页浏览预览与 CodeMirror 6 HTML 源码编辑之间切换，并支持一键在系统浏览器中打开。
- **丰富的 Markdown 语法与真实代码高亮**：
  - 基础与 GFM 语法：YAML Frontmatter 语法高亮、标题与自定义锚点（`### 标题 {#id}`）、列表、待办清单、表格、分割线、标准脚注（`[^id]` / `[^id]:` 及跳转）。
  - **120+ 编程语言真实语法高亮**：接入 `@codemirror/language-data` + `@lezer/highlight` 真实解析器并内置 `Makefile` 解析器，统一实时预览、源码模式与分栏预览的浅色/深色语义配色。
  - 扩展与行内 HTML 语法：`++下划线++`、`==高亮==`、`~下标~`、`^上标^`、多行 GitHub/Obsidian Callout（`> [!NOTE|TIP|IMPORTANT|WARNING|CAUTION]`）、缩略语定义与悬停提示（`*[HTML]: ...`）、行内 HTML 标签（`<u>`、`<b>`、`<i>`、`<s>`、`<mark>`、`<sub>`、`<sup>`、`<code>`、`<kbd>`、`<a>`、`<span>`/`<font>` 颜色、`<img>`、`<center>`）、Emoji 短码（如 `:rocket:`）。
  - 可视化扩展（按需懒加载，不拖慢冷启动）：**KaTeX** 行内/块级 LaTeX 数学公式、**Mermaid** 流程图/思维导图/时序图。
- **高效编辑辅助、双链维护与列编辑**：
  - 空行或空格后输入 `/` 唤出格式插入菜单；**选中文本后输入 `*`、`~`、`=`、`+`、`` ` ``、`$`、括号或引号自动包裹选中文字**而非覆盖。
  - **VS Code 风格列编辑与多光标编辑**：支持 `Alt + 左键拖拽` 矩形列选、`Alt + 左键点击` 添加光标、`Ctrl + Alt + ↑/↓` 上下增光标、`Ctrl + D` 逐个选中相同词、`Esc` 退出多光标。
  - **双向链接补全、断链提示与重命名引用同步**：输入 `[[` 触发当前工作区文件模糊补全，支持标准相对路径 `[笔记名](相对路径.md)` 与 `[[双链语法]]`（`Ctrl / Cmd + Click` 跳转文件或 `#标题`）；实时预览自动检测失效双链并以暗红虚线提示；重命名文件时自动扫描全库引用并弹窗询问是否一键同步更新链接（自动跳过代码块）。
  - 可折叠目录大纲（点击定位 + 滚动高亮当前章节）与右侧仿 VS Code 风格高 DPI 微缩排版缩略图（支持独立开关与拖拽定位）。
  - **大文件自动降级**：单文件超过 `512 KB` 自动切换为高性能单栏源码模式并关闭重型内联组件，保障流畅不卡顿。

### 3. 跨平台图片与附件管理
- **自定义本地资源协议 `folia-asset://`**：在 Rust 侧校验工作区安全边界、规范化中文与空格路径，自动兼容 Obsidian 风格的 `_resources` 附件目录回退解析，并返回 `Cache-Control: no-store`，确保相对路径图片在 Windows / macOS / Linux 三端一致渲染。
- **粘贴与拖拽自动落盘**：剪贴板截图粘贴或外部图片拖入编辑器自动保存至指定目录（支持当前笔记子目录 `./images`、同级目录、工作区统一附件目录），自动插入 POSIX 风格相对路径。
- **底部可折叠附件栏**：浏览当前笔记所在目录及常见子目录中的图片、PDF 与其他附件，随文件增删自动实时刷新，支持缩略图预览、一键插入 Markdown 引用、复制相对路径与灯箱大图查看。

### 4. 安全防覆盖、本地版本历史、编码无损与崩溃恢复
- **本地编辑版本历史（零笔记库污染）**：自动按时间间隔（默认 5 分钟，可自定义间隔与单文件保留上限）记录去重快照，支持 `Ctrl+S` 手动打点、首次编辑前基线快照与恢复前自动备份；全部快照存放在应用数据目录（便携版为 `data/history/`），绝不向笔记库写入任何隐藏文件；支持历史列表浏览、行级 Diff 对比、预览与一键恢复。
- **编码与换行符无损保留**：自动识别 UTF-8、UTF-8 BOM、UTF-16 与 GB18030/GBK 等旧文档编码，并记录原始 `LF` / `CRLF` 换行符，保存时按原格式写回。
- **自动保存 + 文件监控防覆盖状态机**：Rust 侧通过 `notify` 防抖监听 + `blake3` 内容哈希 + `SelfWriteGuard` 自写登记表，彻底杜绝自动保存触发误弹窗；外部编辑器修改正在编辑的脏文件时，拦截写入并弹出顶部非阻塞冲突条（支持 **行级 Diff 对比** / **重新加载** / **保留当前版本**）。
- **原子写入 & 崩溃恢复**：保存采用同目录临时文件原子替换；未保存内容定期写入恢复草稿，异常退出重启后自动提示一键恢复。

### 5. 统一搜索、多标签分栏、双文件 Diff 与工作台记忆
- **左侧栏统一过滤与多线程全文检索（`Ctrl / Cmd + Shift + F`）**：空白时显示完整文件树，输入关键词即时同步过滤文件名并触发基于 ripgrep 同源 Rust `ignore` + `grep-searcher` 的多线程并发正文搜索（支持大小写敏感、全字匹配、正则表达式、按工作区过滤、大文件跳过与输入变更即时取消）。
- **增强标签栏**：支持标签溢出横向滚轮/左右箭头滚动、全部标签下拉列表、**固定标签页**（右键固定，归集左侧防误关）、**鼠标拖拽自由排序**。
- **灵活的 2 分栏 / 3 分栏视图（带激活栏提示与可拖动分隔条）**：
  - 顶栏分栏按钮支持左右分栏与上下分屏均按 **单栏 → 2 分栏 → 3 分栏 → 单栏** 循环切换；
  - 支持 **`Ctrl / Cmd + 点击` 多选 2～3 个标签页**一键合并为 2 分栏 / 3 分栏；
  - 支持**鼠标按住标签页拖至编辑区左右边缘**直接拆出新分栏，或拖入其他分栏跨栏移动；
  - 分栏模式下当前聚焦栏顶部显示细强调线，新开文档精准落入聚焦文档栏并自动避让终端栏；分隔条支持自由拖拽调节宽度/高度，双击恢复均分。
- **内置双文件行级差异对比（`@codemirror/merge`）**：可通过以下 3 种方式随时唤出：
  1. 在**左侧文件树**中右键任意 Markdown 文件 →「与当前打开文件 Diff 对比」；
  2. 在**顶栏标签页**中右键另一标签页 →「与当前标签 Diff 对比」，或按住 `Ctrl` 选中 2 个标签页后点击「对比差异」；
  3. 当文件被外部程序修改产生冲突时，点击顶部冲突条的「对比差异」。
- **单实例、系统托盘与工作台状态记忆**：内置单实例防重复启动（重复打开自动唤醒已有窗口），支持可配置的最小化/关闭到系统托盘；主窗口隐藏初始化并在主题与布局就绪后一步呈现，自动记忆窗口最大化状态、已开标签页、固定状态、编辑模式、分栏比例与排序。

### 6. 多语言界面、YAML 主题配色、快捷键手势与导出
- **四语界面即时热切换**：内置**简体中文、繁體中文、English、日本語**，默认自动跟随系统语言，可在「设置 → 界面主题与语言」中随时切换立即生效。
- **16 套内置纸感主题 + 无限自定义主题**：内置 10 套浅色主题与 6 套深色主题，顶栏提供一键深浅模式切换；支持彩色渲染 / 单色渲染、圆角风格、边栏始终深色、自定义字体/字号/行距与界面缩放。
- **可视化微调 & YAML 配色代码编辑**：支持新建、更新与删除自定义主题卡片，支持像 YAML 代码一样直接编辑、**复制 / 粘贴 / 导入 `.yaml` / 导出 `.yaml`** 分享配色方案。
- **可自定义快捷键与鼠标手势**：所有全局快捷键与右键鼠标手势均可在设置中可视化录制与编辑。
- **HTML & PDF 导出**：
  - 导出单文件 HTML（自动应用当前主题配色，并将本地相对图片转为 Base64 内嵌以支持离线分享）。
  - 导出 PDF（调用系统打印配合专用 `@media print` 排版样式，零额外包体膨胀）。
- **自动更新检查**：设置中心内置「关于与更新」，支持启动时自动检查或手动查询 GitHub Releases 新版本并跳转下载。

## 技术栈与架构

| 模块 | 技术选型 |
| :--- | :--- |
| **桌面框架** | Tauri 2（Windows WebView2 / macOS WKWebView / Linux WebKitGTK） |
| **前端框架** | Vue 3 + TypeScript + Pinia + Vite |
| **编辑器内核** | CodeMirror 6（`@codemirror/*` + `@codemirror/merge`） |
| **后端运行时** | Rust（`std::fs`, `trash`, `notify`, `ignore`, `grep-searcher`, `encoding_rs`, `chardetng`, `blake3`） |
| **扩展渲染与导出** | `marked` + `markdown-it` + `katex` + `mermaid`（动态懒加载） |

## 本地开发与构建

### 环境依赖
- **Node.js** 20+（推荐 LTS）
- **Rust** 稳定版工具链（`rustup` + `cargo`）
- **系统 WebView / 编译工具**：
  - **Windows**：Edge WebView2 Runtime（Windows 10/11 通常已预装）+ MSVC Build Tools 或 GNU 工具链
  - **macOS**：Xcode Command Line Tools（`xcode-select --install`）
  - **Linux (Ubuntu/Debian)**：
    ```bash
    sudo apt-get update
    sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf libssl-dev libxdo-dev
    ```

### 常用命令

```bash
# 1. 安装前端依赖
npm install

# 2. 启动桌面开发模式（热重载）
npm run tauri dev

# 3. 前端类型检查与生产构建
npm run build

# 4. 运行前端单元测试（Vitest）
npm test

# 5. 运行 Rust 后端集成测试
cargo test --manifest-path src-tauri/Cargo.toml --test core_tests

# 6. 打包当前平台发布安装包
npm run tauri build
```

> **Windows PowerShell 提示**：若系统限制执行 `npm.ps1`，可将上述命令中的 `npm` 替换为 `npm.cmd`（例如 `npm.cmd run tauri dev`）。
